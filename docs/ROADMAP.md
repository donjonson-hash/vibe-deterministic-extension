# Roadmap

Статус: **черновик объёма MVP, ждёт утверждения владельца** (2026-10-22).
Основа: [ADR-0001](decisions/0001-chrome-mv3-llm-adapters.md).

## Суть MVP

- **Проблема:** вайбкодер берёт изменения у LLM вслепую. Код копируется из чата
  кусками, вставка ломает файл, неясно, что поменялось по смыслу, отката нет.
  Сейчас это решается так: copy-paste из ChatGPT или Claude, `git diff` руками,
  либо IDE с AI (Cursor, Copilot) со встроенным accept/reject.
- **Пользователь (допущение):** вайбкодер, который работает с LLM через браузер
  и свой ключ, без AI-IDE. Сначала сам автор и 5–10 знакомых бета-тестеров.
- **Главная работа:** «дал задание к файлу → получил *проверенный* патч → увидел
  смысл изменения → принял целиком или отказался → сохранил файл».
- **Успех (допущение, уточнить):** у бета-тестеров ≥ 50% запусков заканчиваются
  принятым патчем и скачанным файлом. Для каждого отказа известна проверка,
  на которой он случился.

## Next — сразу после MVP (Should)

- Папка проекта через File System Access API, запись в файл с проверкой хеша
  (файл не изменился с момента чтения).
- Патчи в несколько файлов одной командой.
- Ollama без ручной настройки `OLLAMA_ORIGINS`: снимать `Origin` через
  `declarativeNetRequest` (так делает, например, Page Assist). Нужна проверка политики CWS.
- Streaming ответа, показ токенов и стоимости запроса.
- Языки помимо TS/JS (Python, JSON, YAML) через парсеры, которые уже есть в Code Compare Local.
- Нативный адаптер Gemini и structured outputs для каждого провайдера, если OpenAI-compat окажется слабым.
- Локализация интерфейса на русский.

## Won't — сейчас не делаем

- VS Code-версия: заморожена на `45bc30a`.
- Голосовой ввод: Web Speech API отправляет звук в Google.
- Content scripts в web-IDE и чаты (StackBlitz, Replit, claude.ai, ChatGPT).
- Свой backend, прокси для LLM, аккаунты, платежи, серверная телеметрия.
- Исполнение кода в песочнице «для проверки».
- `chrome.storage.sync` для ключей.
- Firefox.
- Лог с хеш-цепочкой, заявления о «детерминированной генерации».

## Риски и как их проверить дёшево

| Гипотеза | Риск | Проверка до кода |
|---|---|---|
| LLM выдаёт `searchBlock`, который точно совпадает с файлом | Высокий: если доля отказов большая, продукт раздражает | **Спайк-оценка:** Node-скрипт на текущем конвейере из `main`, 20 реальных задач × Claude / GPT / локальная модель → доля прошедших с первой попытки и после повторов. 1–2 дня и примерно $5–20 API |
| Локальные модели справятся с форматом | Средний | Тот же спайк на Ollama, бесплатно, Ollama уже стоит |
| Вайбкодеры откроют отдельную вкладку, хотя в IDE уже есть accept/reject | **Самый высокий:** спрос | Этап 1 (Try example) показать 5–10 людям до адаптеров; Unlisted-ссылка |
| CWS пропустит `optional_host_permissions` + отправку кода провайдеру | Средний | Отправить оболочку этапа 1 Unlisted с уже объявленными разрешениями |

Проверено 2026-10-22:
- `api.anthropic.com` отвечает на CORS preflight с origin `chrome-extension://`
  (`access-control-allow-origin: *`, разрешён `anthropic-dangerous-direct-browser-access`).
  Нужен ли этот заголовок при валидном ключе, не проверялось: передаём его всегда.
- Ollama 0.34.1 с настройками по умолчанию отвечает **403** на запросы с origin
  `chrome-extension://…`. В MVP — инструкция `OLLAMA_ORIGINS=chrome-extension://<id>`,
  в Next — обход через `declarativeNetRequest`.

## Оценка и этапы

Must целиком — **L** (примерно 3–4 недели). Больше всего работы в переносе
парсера и линтера в браузер, в UI диффа и принятия и в Playwright на установленном
расширении. Адаптеры сами по себе маленькие.

| Этап | Результат, который можно показать | Размер |
|---|---|---|
| 0. Спайк-оценка | Таблица: доля прошедших патчей по провайдерам → решение «search/replace или перезапись файла» | S |
| 1. Офлайн-оболочка | Установленное расширение: Try example → дифф → принять → Undo → скачать. Показать людям, отправить Unlisted | M |
| 2. Anthropic | Реальные патчи от Claude с BYOK, согласием и автоисправлением | M |
| 3. Любой провайдер + бета | OpenAI-compat с пресетами, privacy policy, store kit → бета-тестеры | M |

## Решения, которые нужно принять заранее (`/tech-decision`)

1. **Язык исходников:** TypeScript + esbuild (как сейчас и как в Code Compare Local)
   или чистые `.mjs`, как в ядре deterministic-extensions.
2. **Парсер в браузере:** `typescript` (≈9 МБ, уже используется в коде) или
   `@babel/parser` с TS-плагином (уже есть в семействе).
3. **UI диффа:** `@codemirror/merge` из Code Compare Local или свой минимальный.
4. **Формат ответа LLM:** search/replace (сейчас) или перезапись файла целиком
   с диффом на нашей стороне. Решается по итогам этапа 0.
