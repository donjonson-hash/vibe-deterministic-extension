# Vibe — локальная проверка изменений

Chrome MV3 офлайн-пилот: открыть TS/JS → вставить предложение → проверить → просмотреть diff → принять целиком → Undo/Redo → скачать.
Генерация LLM не считается детерминированной. Повторяемыми являются проверки при одинаковых входах и политике.

```bash
npm ci
npm run typecheck
npm test
npm run test:evidence
npm run package:chrome
npx playwright install chromium
npm run test:chrome
```

Распакуйте `artifacts/vibe-chrome-0.2.0.zip` и загрузите папку через «Загрузить распакованное расширение» в chrome://extensions в режиме разработчика. Нажмите значок расширения. «Попробовать пример» работает без сети и ключа.

- Загруженный код не исполняется. Нет content scripts, разрешений на сайты и сетевых запросов.
- Кандидат виден до принятия; старые ответы и предложения инвалидируются при изменении входов, Undo/Redo и отмене.
- BOM и исходные переводы строк сохраняются; неверный UTF-8 отклоняется.
- Лимиты: 1 MiB, 200000 UTF-16 единиц, 4000 строк. Лимит diff: 2000 изменений строк. Неполный diff блокирует принятие.
- Проверяется синтаксис и небольшой набор правил, а не типы или выполнение намерения. Смысловой отчёт не является доказательством эквивалентности.
- История живёт в текущей вкладке; файл сохраняется скачиванием. Доступ к папке проекта и LLM-адаптеры пока не подключены.

## Drydock

Сначала проверьте предложение и нажмите «Скачать кандидат для Drydock». В установленной локальной копии Shipit должны быть доступны зависимости CLI.

```bash
python3 scripts/drydock-export.py --candidate /path/greet.ts --shipit /path/shipit --python /path/shipit-venv/bin/python --output /path/evidence.json
```

Загрузите `evidence.json` в блок Drydock, пока показан тот же кандидат. Импорт сверяет имя и SHA-256 точных байтов, включая BOM. Полный исходный отчёт, ограничения и неизвестные результаты остаются видимыми. Это **проверка одного файла**, без зависимостей и контекста проекта; статус всегда `partial`. Импорт не является подписанной аттестацией. Кандидат копируется во временную папку и статически анализируется, но не запускается.

Политика проверок `proposal-check-v2` заменяет токеновое сравнение структурным AST и делает лимиты обязательными. Старые результаты нужно пересчитать; принятые пользовательские файлы не мигрируют.

VS Code v0.1 остаётся историческим прототипом (`src/extension.ts`, `npm run build`). В Chrome-пакет он и его исполняющая песочница не входят. Chrome Web Store, внешние LLM и Ghidra в этот пилот не входят.
