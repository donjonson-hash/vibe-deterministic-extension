# Vibe Deterministic Extension

![Deterministic CI & Build](https://github.com/donjonson-hash/vibe-deterministic-extension/actions/workflows/release.yml/badge.svg)

Каркас расширения для **вайбкодинга** (VS Code / Cursor), объединяющий высокоуровневое управление намерениями (Voice & Intent Flow) со **строго детерминированным конвейером верификации кода**.

Нейросеть (LLM) выступает исключительно как изолированный генератор гипотез с фиксированными параметрами (temperature = 0, seed = 42, JSON Schema), а применение любого патча контролируется тройным щитом: **AST-парсером**, **статическим линтером безопасности** и **изолированной V8-песочницей**.

---

## Ключевые принципы архитектуры

1. **Строгий детерминизм контекста (ContextManager)** — сбор импортов, экспортов и сигнатур функций выполняется через TypeScript Compiler API без участия LLM и фиксируется криптографическим хешем SHA-256.
2. **Идемпотентный слой LLM (DeterministicLLMClient)** — принудительный JSON Mode, temperature = 0 и локальный SHA-256 кеш ответов (повторные запросы на том же контексте возвращаются за 0 мс).
3. **Тройной конвейер фильтрации и самоисправления (AutoFixLoop)**:
   - **AstValidator** — проверка синтаксической целостности в памяти (in-memory) до записи на диск.
   - **LinterRunner** — блокировка eval(), new Function(), debugger и нестрогой типизации (any).
   - **SandboxRunner** — тестовый прогон модуля в отдельном worker_thread и контексте node:vm: таймаут (в том числе для бесконечных цепочек промисов), лимит памяти, запрет eval/new Function, зависимости (`require`) заменяются инертными заглушками. Это защита от случайных ошибок и зависаний, а не граница безопасности для намеренно вредоносного кода.
   - При любой ошибке лог автоматически возвращается в LLM для исправления (до 3 попыток).
4. **Атомарная Машина Времени (TimeMachine)** — создание неизменяемых (Object.freeze) снапшотов с проверкой целостности по SHA-256 и откат в один клик или голосовой командой.
5. **Семантический дифф (SemanticDiffEngine)** — сравнение старого и нового AST с фильтрацией косметического шума (пробелов/комментариев) и расчетом уровня риска (LOW / MEDIUM / HIGH).
6. **Криптографический аудит (DeterministicLogger)** — журнал событий, связанный в непрерывную хеш-цепочку (Hash Chain).

    ├── .github/workflows/release.yml   # CI/CD: автопроверка типов, тесты и сборка

    │   ├── extension.ts                # Точка входа расширения и регистрация команд
    │   ├── core/
    │   │   ├── contextManager.ts       # Детерминированный парсинг AST и SHA-256 слепок
    │   │   ├── stateMachine.ts         # Конечный автомат состояний
    │   │   └── sandboxRunner.ts        # VM-песочница в воркере с таймаутом и лимитом памяти
    │   ├── llm/
    │   │   ├── client.ts               # Клиент LLM (temperature=0, seed=42, SHA-256 cache)
    │   │   ├── promptTemplates.ts      # Системные и пользовательские шаблоны промптов
    │   │   └── schemaParser.ts         # Валидатор строгой JSON-схемы патчей
    │   ├── pipeline/
    │   │   ├── astValidator.ts         # In-memory проверка синтаксиса TypeScript
    │   │   ├── linterRunner.ts         # AST-фильтр безопасности (no-eval, no-any)
    │   │   └── autoFixLoop.ts          # Цикл автоматического возврата ошибок в LLM
    │   ├── ui/
    │   │   ├── commandCenter.ts        # Классификатор интентов (FEATURE, BUGFIX, REFACTOR)
    │   │   ├── voiceInput.ts           # Очистка голосовых команд от слов-паразитов
    │   │   ├── semanticDiff.ts         # Сравнение AST и оценка риска изменений
    │   │   └── timeMachine.ts          # Транзакционные снапшоты и мгновенный откат
    │   └── utils/
    │       ├── crypto.ts               # Вычисление SHA-256 хешей
    │       ├── patch.ts                # Однозначная замена searchBlock -> replaceBlock
    │       └── logger.ts               # Логгер с проверкой целостности хеш-цепочки
    └── tests/
        └── unit/                       # Модульные тесты всех подсистем

## Быстрый старт и разработка

Установка зависимостей:

    npm install

Строгая проверка типов TypeScript:

    npm run typecheck

Запуск модульных тестов (на встроенном раннере node:test):

    npm test

Сборка расширения в директорию dist/:

    npm run build

## Доступные команды расширения (VS Code)

- **vibe.executeIntent** — запустить вайб-интент (текстом или голосом) через детерминированный конвейер.
- **vibe.rollbackLast** — мгновенно откатить последнее изменение через TimeMachine с проверкой SHA-256.

Работает с активным TypeScript/JavaScript файлом; патчи LLM могут менять только этот файл.
Ключ LLM берется из переменной окружения `VIBE_LLM_API_KEY` (OpenAI-совместимый endpoint);
без ключа используется локальный демо-ответ, который подходит только к демонстрационному коду с `// old`.
